# Benchmark data — Thien / DAT-12

Required initial candidates: Chess, Mushroom, Retail, T10I4D100K. Large files here
are ignored by Git. Prefer existing public Hugging Face/Kaggle mirrors per the brief;
verify their bytes/provenance against the [SPMF dataset catalog](https://www.philippe-fournier-viger.com/spmf/index.php?link=datasets.php)
or [FIMI](http://fimi.uantwerpen.be/data/).

Before measurement, commit a small data manifest recording dataset name/version,
source URL, mirror URL, license/usage terms, filename, SHA-256, actual transaction
and distinct-item counts, mean width, and preprocessing. No mirror or stats are
asserted until verified. Download/preparation commands belong in notebook modules.
