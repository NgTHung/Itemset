\section{Cài đặt}
Hung phụ trách. Trình bày Eclat theo bài báo gốc~\cite{zaki2000}, biểu diễn dọc,
tidset, phép giao, DFS theo prefix, tỉa nhánh và độ phức tạp.
\subsection{Hợp đồng và cài đặt cơ bản}
Bổ sung ví dụ truy vết, cấu trúc dữ liệu, định dạng SPMF và tham số CLI.
\subsection{Kiểm thử và tối ưu hóa}
Bổ sung kiểm thử trên ít nhất năm CSDL, so khớp chính xác với SPMF, và kỹ thuật
tối ưu đã cài đặt kèm bằng chứng đo so với bản cơ bản. Chưa có số liệu ở bản khung.
